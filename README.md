# How to run the app
- requires Python version 3.14
- download the repo from GitHub
- extract the archive
- use eg. Terminal to switch to the project folder and run
    ``` ./setup ```
- make sure the RESTFramework is also installed, otherwise enter:
    ``` pip install djangorestframework ```
- create a superuser to make the admin interface accessible (optional)
    ``` python manage.py createsuperuser ```
- run the server
    ``` python manage.py runserver ```
